# Product Reviews Blog (Мини-блог о еде и напитках)

> Современный, легковесный и быстрый мини-блог для создания отзывов об продуктах.

---

## Технологический стек

Проект построен на базе современного фронтенд-окружения:

*   **Фронтенд-основа:** React 19.2 (Single Page Application)
*   **Сборщик проекта:** Vite 8.3
*   **Линтинг:** ESLint 10.1 (с плагинами для хуков и React Refresh)

## 🌟 Основной функционал

*   **Каталог карточек:** Наглядный каталог с мини карточками еды и напитков с названием продукта.
*   **Система отзывов:** Интерактивный мини карточки в каталоге открывают описание и отзыв.
*   **Сверхбыстрый UI:** Мгновенный отклик интерфейса за счет оптимизации сборки в Vite.

## 🚀 Запуск

Инструкция по развертыванию и запуску приложения на локальном компьютере.

### Шаги установки и запуска

1. **Клонируйте репозиторий проекта:**
   ```bash
   git clone https://github.com
   ```

2. **Перейдите в папку с проектом:**
   ```bash
   cd product-reviews-blog
   ```

3. **Установите все зависимости:**
   ```bash
   npm install
   ```

4. **Запустите локальный сервер для разработки:**
   ```bash
   npm run dev
   ```

5. **Откройте приложение:**
   В терминале появится ссылка (`http://localhost:5173`), кликните по ней или вставьте в адресную строку браузера.
